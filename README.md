# Student_Performance_Analysis
This repository contains an Excel data analysis project based on student performance and placement datasets.

Project Overview
- Dataset Used: college_student_placement_dataset22222222.xlsx
- Tools Used: Microsoft Excel (Pivot Tables, Formulas, Data Analysis)

Key Analysis & Questions Solved
1.Total student count in the dataset.
2. Average IQ and CGPA of students.
3. Minimum and Maximum CGPA calculations.
4. Checking for missing/blank values using `COUNTBLANK`.
5. Analyzing the relationship between project completions and academic performance using Pivot Tables.

Files Included
- college_student_placement_dataset22222222.xlsx - Main dataset and analysis sheet.
- Excel Data Analysis Project.txt - Project notes and queries.
